# 4. كيف يتغير الموقع؟

وهذه النقطة مهمة جدًا.

لا نريد:

> صفحة التجارة زرقاء بالكامل
> صفحة الصحة حمراء بالكامل
> صفحة البناء برتقالية بالكامل

هذا سيجعل الموقع يبدو كأنه عدة مواقع.

بل:

**الهوية الأساسية ثابتة + لون المجال يظهر في العناصر التفاعلية.**

مثلاً:

```text
الخلفية
       ↓
      أبيض/رمادي فاتح

العناوين
       ↓
      داكن

الأزرار
       ↓
      لون المجال

Progress Bar
       ↓
      لون المجال

أيقونات المجال
       ↓
      لون المجال

Glow / 3D
       ↓
      لون المجال

الاختيارات المحددة
       ↓
      لون المجال
```

# 6. لمسة الـ3D

أقترح عدم استخدام 3D ثقيل.

بدلاً من مجسمات ضخمة، نستخدم:

### Floating Cards

بطاقات تطفو قليلًا:

```text
       ┌───────────────┐
       │   📊 127       │
       │ مشكلة مكتشفة  │
       └───────────────┘
             ↗
          ┌───────┐
          │  ✓ 38 │
          │ تحقق  │
          └───────┘
```

مع:

```css
transform: translateY(-4px);
box-shadow: 0 15px 35px rgba(...);
```

والـhover:

```text
الحالة العادية
     ↓
  translateY(0)

Hover
     ↓
  translateY(-6px)
  rotateX(2deg)
```

هذا يعطي إحساس 3D بدون أن يتحول الموقع إلى لعبة.

# 7. اختيار المجال — أهم شاشة

هذه الشاشة يجب أن تكون جميلة جدًا لأنها نقطة التحول في الـDynamic Survey.

مثلاً:

```text
              ما هو مجال عملك؟

        اختر المجال الذي تريد المشاركة عنه


 ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
 │     🏪       │  │     🏗️       │  │     🏥       │
 │   التجارة    │  │ البناء       │  │   الصحة      │
 └──────────────┘  └──────────────┘  └──────────────┘

 ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
 │     🌾       │  │     🔧       │  │     🎓       │
 │   الفلاحة    │  │ الصيانة      │  │ التعليم      │
 └──────────────┘  └──────────────┘  └──────────────┘
```

عند تمرير الماوس:

```text
     ┌─────────────────┐
     │       🏪        │
     │     التجارة     │
     │                 │
     │  اكتشاف مشاكل   │
     │ المخزون والمبيعات│
     └─────────────────┘
          ↑
       3D Hover
```

وعند الاختيار:

**كل الموقع ينتقل تدريجيًا إلى لون المجال.**

مثلاً:

```text
التجارة
   ↓
#2563EB

Animation
   ↓
0.3s
```

# 9. الـProgress Bar نفسه يتغير

هذه لمسة جميلة.

إذا اختار المستخدم:

**الصحة**

يصبح:

```text
🏥 الصحة

████████████░░░░░░

     60%
```

باللون الصحي.

إذا اختار:

**البناء**

```text
🏗️ البناء

████████████░░░░░░

     60%
```

باللون البرتقالي.

لكن:

**الشكل والمكونات لا تتغير.**

# 10. شاشة اكتشاف المشكلة

هذه أهم شاشة في المشروع.

لا تجعل السؤال:

> هل تريد تطبيقًا لحل هذه المشكلة؟

لأن هذا قد يؤثر على النتائج.

الأفضل:

```text
ما أكثر مشكلة تزعجك في هذا العمل؟

┌───────────────────────────────────────────┐
│                                           │
│ اكتب المشكلة كما تحدث في الواقع...       │
│                                           │
│                                           │
└───────────────────────────────────────────┘

متى حدثت آخر مرة؟

○ اليوم
○ هذا الأسبوع
○ هذا الشهر
○ منذ مدة طويلة
○ لا أتذكر
```

ثم:

```text
كم مرة تحدث تقريبًا؟

○ يوميًا
○ عدة مرات أسبوعيًا
○ أسبوعيًا
○ شهريًا
○ نادرًا
```

هنا نحصل على **بيانات حقيقية قابلة للتحليل**.
